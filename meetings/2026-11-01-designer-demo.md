# Tether Robot Capabilities and Demo Direction

- Robot (Tether) can maneuver, grab light objects, and build modular structures
- Current MVP looks industrial: bare metal arm, no aesthetic treatment
- Placement confirmed in Area D; visitors enter and turn right, so Tether is among the first things seen
- Design team (Caroline + one other) assigned to Tether’s platform, no separate team

# Demo Concept: Curious Robot Exploring Nature

- Core vibe: Pixar lamp-style curiosity, lively and animated movement
- Narrative frame: robot discovering and interacting with nature, tech helping nature
  - Inspired by Ariel (Little Mermaid) collecting unknown objects with curiosity
  - Reference: another team’s robot arms extracting material from old tech to help plants bloom
- Demo loop: robot moves between two locations, shifting objects pile-to-pile
  - Avoids a clear “beginning and end” that would break the illusion during reset
  - Intermediate lively motion added between building actions to keep it engaging
- Structure likely a spiral or staircase form to span width, not just height
  - Multiple docking ports along the path for the arm to traverse and place objects
  - Arm can carry small objects while climbing if object fits within docking port depth
- Battery swap planned mid-demo; sign idea: “Tether is resting”
- Aesthetic direction: paint linkages green, add fake moss to static parts
  - End effectors (spinning) harder to decorate; painting the frame is feasible
  - Jack (Tether team) has prior experience making robot arms look organic
