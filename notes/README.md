# notes/

**Nothing in this folder is authoritative.** It's research, AI-agent output, drafts, and scratch work.

Name files `YYYY-MM-DD-<person>-<topic>.md`. The person is whoever owns the work, even if an AI agent wrote it.

If something here turns out to matter, promote the fact into `truth/` and link back. Old notes can be moved to `archive/` at any time.
